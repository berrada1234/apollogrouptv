## Keyword cannibalization

Pairs checked because they sit close together, each with a distinct intent: how-to-update-apollo-group-tv (all devices except Fire TV) vs update-apollo-tv-firestick; is-apollo-tv-down (outage check) vs apollo-group-tv-status-code-404 (one error code); /guides/fire-tv-android-tv (setup) vs apollo-tv-downloader-code (the tool) vs best-firestick-for-iptv (buying); /apollo-group-tv-renewal (renewing) vs /payment-guides/how-checkout-works (first purchase). Reserved keywords are enforced by `tests/unit/blog.test.ts`.

## Technical

- robots.txt allows public pages, blocks private areas, and lists the sitemap. HTTP → HTTPS is a 301 and HSTS is set. Trailing slashes 308-redirect.
- Structured data: Organization and WebSite (home), BreadcrumbList (all pages), BlogPosting, Article, Service, SoftwareApplication, HowTo, FAQPage, ItemList, AboutPage, ContactPage. All JSON-LD parses. FAQPage markup matches visible Q&A, which Google's guidelines require; Google now shows FAQ rich results only for authoritative government and health sites, so expect no FAQ snippets. HowTo rich results were retired by Google in 2023; the markup is harmless.
- Server response time from outside the US: about 0.4 s on every page tested. PageSpeed Insights couldn't run (shared API quota reached).
